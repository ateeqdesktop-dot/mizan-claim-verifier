# قرار المشروع — Mizan Enhanced Portfolio Release

## القرار

تم اعتماد **ميزان — Mizan: Evidence-Backed Arabic Claim Verification** بوصفه المشروع الأنسب للنسخة المحسنة. لا يعتمد القرار على سهولة التنفيذ فقط؛ بل على التوازن بين القيمة الواقعية، العمق التقني، الأصالة، قابلية القياس، وقوة العرض في Portfolio.

## منهج المقارنة

استُخدمت أوزان صريحة تعكس أولوية المهمة: القيمة الواقعية 25%، العمق التقني 25%، الأصالة 20%، قابلية التنفيذ 15%، وقوة Portfolio 15%. كل معيار قُيّم من 1 إلى 5 ثم حُوّل إلى درجة من 100.

| الترتيب | المشروع | الدرجة | سبب القرار |
|---:|---|---:|---|
| 1 | ميزان: التحقق العربي بالأدلة | **97** | يعالج مشكلة اجتماعية وبحثية واضحة، ويجمع NLP والاسترجاع والتفسير والامتناع مع بيانات حقيقية وDemo قابل للمراجعة |
| 2 | كشف سلوك التهديدات السيبرانية متعدد الإشارات | 90 | عميق وعملي، لكن توحيد صيغ بيانات IDS/IoT/Malware والتحقق من التراخيص يرفع المخاطر |
| 3 | فحص العيوب الصناعية وتحديد موضعها | 86 | قابل للعرض بصريًا وذو قياس واضح، لكن المجال مزدحم وترخيص البيانات غير تجاري |
| 4 | الصيانة التنبؤية مع عدم اليقين | 86 | قيمة عملية قوية، إلا أن C-MAPSS مستخدم بكثرة وتحديات ترخيصه وإعادة تمييزه أكبر |
| 5 | مراقب الشذوذ المتدفق الواعي بتكلفة الإنذار | 85 | مناسب للأنظمة الحية، لكن Benchmark ناضج ويحتاج Demo streaming كاملًا ليكون مميزًا |
| 6 | تنبؤ الطلب والطاقة مع كشف الشذوذ | 81 | مفيد تجاريًا، لكن اختيار مصدر بيانات ثابت وتعريف المتغيرات يحتاجان عملًا إضافيًا |
| 7 | كاشف الأخبار الزائفة العربية | 79 | قابل للتنفيذ بسرعة، لكنه مكرر إذا اقتصر على real/fake دون دليل أو تفسير |
| 8 | موصي الموارد التعليمية العربية وفجوة المهارات | 77 | فكرة جيدة، لكن لا توجد بسهولة بيانات تفاعل حقيقية ومرخصة لتقييم التوصية |

## لماذا ميزان؟

الاختيار يجمع فجوة عربية واضحة مع مكوّن AI قابل للقياس. فبدل أن يقول النظام إن النص صحيح أو زائف دون تفسير، يعيد تصنيفًا احتماليًا، ومقالات تحقق مرشحة، وجملًا دليلية ومصادر، أو يعلن صراحة أن الأدلة غير كافية. هذا يجعل النظام مناسبًا للتقييم الأكاديمي وللعرض أمام صاحب عمل، مع إبقاء حدوده واضحة وعدم تقديمه كجهة تحقق رسمية.

## نطاق الإصدار المحسن

| الطبقة | نطاق الإصدار |
|---|---|
| البيانات | AraFacts الأساسية المرخصة للاستخدام غير التجاري، مع منع رفع البيانات الخام إلى GitHub |
| النموذج | Claim-only classifier تشغيلي، مع Majority baseline ومقارنة مصنف خطي إضافي في التقييم |
| الأدلة | استرجاع lexical قابل لإعادة الإنتاج مع ترتيب الجمل والمصادر |
| السلامة | عتبة ثقة وعتبة صلة تعيدان `insufficient_evidence` عند عدم كفاية الدعم |
| العرض | Demo عربي RTL محلي فوق FastAPI يعرض القرار والدليل والمرشحين وحالات الخطأ |
| الجودة | اختبارات وحدة وتكامل وحالات حواف، GitHub Actions، فحص compile وdiff وأسرار أساسي |
| التوثيق | README، تصميم، معمارية، تقييم، Model Card، قيود، ترخيص، ومصادر |

## ما لن ندعيه

لا يدعي الإصدار أن الاسترجاع lexical يثبت صحة الادعاء، ولا يدعي أداءً متوازنًا للفئات النادرة التي لا تظهر في بعض الاختبارات الزمنية. كما لا يستخدم AuRED مخلوطًا مع AraFacts في التدريب، ولا يجلب صفحات جديدة لحظة الطلب، ولا يقدم حكمًا رسميًا أو قانونيًا أو صحفيًا.
